  <action>
    1. Create `src/documind/ui/components/citations.py` providing:
       - `render_grounding_badge(grounding_status: str, is_abstained: bool)`: Renders strictly distinct visual badges:
         - `verified`: `st.success("Grounding: Verified ✅")`
         - `partially_supported`: `st.info("Grounding: Partially Supported (Some claims lack citations) ℹ️")`
         - `unsupported`: `st.warning("Grounding: Unsupported Claims Intercepted (Conservative Fallback) ⚠️")`
         - `abstained`: `st.info("Grounding: Abstained (No Supporting Evidence) ℹ️")`
         - Enforcement: If `grounding_status != "verified"`, NEVER display a green verified badge.
       - `render_citations(citations: List[Citation], context: FormattedContext)`:
         - Renders a clean divider: "Sources & Verifiable Citations".
         - For each citation in `citations`:
           - Title: `f"[{citation.source_id}] {citation.document_name} — Page {citation.start_page}"`
           - Inside `st.expander`:
             - Physical page span: `Page {citation.start_page} to {citation.end_page}`.
             - Matched Chunk ID: `citation.matched_chunk_id`.
             - 3-Layer verification status:
               - `Syntax Validity: Valid [S1] format ✅`
               - `Metadata Linkage: Mapped to ContextReference ✅` (or `Hallucinated Source ❌`)
               - `Evidence Support: Claim terms confirmed in chunk text ✅` (or `Unverified ⚠️`)
             - Excerpt block: Displays the exact chunk text from `context.references`.
       - `render_abstention_callout(phrase: str, abstention_type: str, fast_path: bool)`:
         - Renders a clean callout explaining the exact reason:
           - Fast-path: "No retrieved document passages exceeded the 0.35 similarity threshold (fast-path rejection in < 15 ms)."
           - Model explicit: "The language model determined the provided documents do not contain sufficient evidence."
           - Fallback unsupported: "The model generated claims without valid citation support, triggering safety abstention."
       - `render_telemetry_expander(telemetry: Dict[str, Any])`:
         - Shows retrieval latency (ms), context build latency (ms), generation latency (ms), prompt/completion tokens, generation TPS, and peak process RAM.
  </action>

  <action>
    1. Create `src/documind/ui/components/chat.py` providing `render_chat_interface()`:
       - **Historical Message Rendering:**
         - Iterates through `st.session_state.messages`.
         - Renders user questions via `st.chat_message("user")`.
         - Renders assistant answers via `st.chat_message("assistant")` with full grounding status badge, answer text, citation expanders, and telemetry.
       - **Empty History Quick-Start Pills:**
         - When no messages exist, displays 3 sample query buttons:
           - "What is chunk overlap?"
           - "How does hybrid search work?"
           - "What is the token-to-word rule of thumb?"
       - **User Query Input:**
         - Captures query from `st.chat_input("Ask a question about your documents...")` or sample pill click.
         - Validates input (silently ignores empty or whitespace-only queries).
         - Appends user message to `st.session_state.messages`.
       - **Primary Answer Rendering Strategy (Synchronous Verified for MVP):**
         - Executes `st.session_state.generator.generate_answer(query)`.
         - If `fast_path_empty_context`: Instantly displays abstention callout and records message.
         - Otherwise:
           - Shows `st.spinner("Retrieving evidence & generating grounded answer...")`.
           - Generates complete `GroundedAnswer` synchronously with full citation resolution.
           - Displays grounding status badge.
           - Displays clean answer text.
           - Displays citation accordions and telemetry expander.
           - Appends completed `GroundedAnswer` record to `st.session_state.messages`.
       - **Optional Provisional Streaming Mode (Controlled via UI toggle in settings):**
         - If user explicitly enables streaming in sidebar settings:
           - Clearly labels streaming box: *"Generating provisional draft..."*
           - Streams tokens via `stream_generate` into `st.write_stream`.
           - Only AFTER stream completion runs `CitationParser.verify_citations`.
           - Replaces the provisional draft with the finalized verified answer card.
           - If conservative fallback downgrades the answer, replaces the text with the abstention callout.
  </action>
