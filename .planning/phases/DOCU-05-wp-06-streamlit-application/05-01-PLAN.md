  <name>Task 2: Implement Multi-PDF Ingestion Manager with Deduplication & Lifecycle Persistence</name>
  <files>src/documind/ui/ingestion_manager.py</files>
  <read_first>src/documind/ingestion/pipeline.py, src/documind/ingestion/pdf_loader.py, src/documind/storage/index.py, src/documind/storage/vector_store.py</read_first>
  <action>
    1. Create `src/documind/ui/ingestion_manager.py` with `IngestionManager`:
       - `__init__(pipeline: Optional[IngestionPipeline] = None, upload_dir: str = "data/uploads", index_dir: str = "data/index")`.
       - `compute_file_hash(file_bytes: bytes) -> str`: Computes SHA-256 hex digest of uploaded buffer before file I/O.
       - `sanitize_filename(name: str) -> str`: Strips path traversal sequences (`../`, `..\\`), control chars, and non-ASCII glyphs.
       - `save_uploaded_file(uploaded_file, file_hash: str) -> Path`: Writes buffer to `data/uploads/{file_hash[:12]}_{safe_filename}`, enforcing 50 MB limit (`max_file_size_bytes = 50 * 1024 * 1024`).
       - `ingest_and_index(uploaded_files, document_index: DocumentIndex, registry: Dict[str, Any], progress_callback: Optional[Callable[[str, float], None]] = None) -> IngestionSummary`:
         - Pre-check: If `file_hash` exists in `registry`, record as `skipped_duplicate` with friendly notice.
         - Inspection: Validates PDF header via `PDFLoader.validate_pdf`. Catches 0-byte or corrupt files.
         - Extraction & Chunking: Ingests via `IngestionPipeline.ingest_file()`. If `extractable_characters == 0`, flags as scanned image-only PDF (informing user that OCR is scheduled for Milestone 2).
         - Vector Insertion: Calls `document_index.add_chunks(chunks)`.
         - Persistence: Saves vector store snapshot to `data/index` via `document_index.vector_store.save("data/index")` and flushes `data/index/document_registry.json`.
         - Updates in-memory `registry` with document details.
         - Returns `IngestionSummary(total_files, indexed_files, skipped_files, total_chunks, errors)`.
  </action>
