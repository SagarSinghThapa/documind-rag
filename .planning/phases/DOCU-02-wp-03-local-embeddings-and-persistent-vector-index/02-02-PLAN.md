<task type="auto">
  <name>Task 1: Implement FaissVectorStore with Crash-Consistent Snapshots and Defensive Loading</name>
  <files>src/documind/storage/vector_store.py, src/documind/storage/__init__.py</files>
  <read_first>src/documind/storage/schemas.py, src/documind/storage/embedder.py, .planning/phases/DOCU-02-wp-03-local-embeddings-and-persistent-vector-index/02-RESEARCH.md</read_first>
  <action>
    1. Define custom exceptions in `src/documind/storage/vector_store.py`:
       - `VectorStoreError(Exception)`
       - `IncompatibleIndexError(VectorStoreError)`: Raised on model name, dimension, metric, or normalization mismatches.
       - `IndexCorruptionError(VectorStoreError)`: Raised on missing files, uncommitted snapshots, corrupt JSON, or checksum failures.
    2. Define abstract `BaseVectorStore(ABC)`:
       - `@property total_vectors -> int`
       - `@property dimension -> int`
       - `add(vectors: np.ndarray, records: List[VectorRecord]) -> int`
       - `search(query_vector: np.ndarray, top_k: int = 5) -> List[SearchResult]`
       - `save(directory: Union[str, Path]) -> None`
       - `load(directory: Union[str, Path], expected_model_name: Optional[str] = None) -> None`
       - `contains_chunk(chunk_id: str) -> bool`
    3. Implement concrete `FaissVectorStore(BaseVectorStore)`:
       - Uses `faiss.IndexFlatIP(dimension)` for exact inner-product (cosine similarity on L2-normalized vectors).
       - Maintains internal `_records: List[VectorRecord]` aligned 1:1 with FAISS integer indices (`0..N-1`).
       - Maintains `_chunk_id_set: Set[str]` for O(1) membership lookups.
       - **Vector validation** on `add` and `search` (Safeguard 5):
         * Enforces 2D array of shape `(N, dimension)` for `add` and `(1, dimension)` or `(dimension,)` for `search`.
         * Enforces `dtype=np.float32` and `np.ascontiguousarray`.
         * Asserts `np.all(np.isfinite(vectors))` (rejects `NaN`, `+Inf`, `-Inf` with `ValueError`).
         * Validates Euclidean norm $\approx 1.0 \pm 1e-3$ when normalization is enabled.
       - **Empty index handling** on `search` (Safeguard 6, 9):
         * If `total_vectors == 0`, immediately returns `[]` without querying FAISS C++ index.
       - **Staged crash-consistent snapshotting** in `save(directory)` (Safeguard 1):
         * Creates a temporary staging directory `directory / f".snapshot_staging_{uuid4().hex[:8]}"` (or sibling).
         * Writes `index.faiss` using `faiss.write_index()`.
         * Writes `metadata.json` containing serialized list of `_records`.
         * Computes SHA-256 checksums of `index.faiss` and `metadata.json`.
         * Writes `manifest.json` with `status: "committed"`, checksums, `model_name`, `dimension`, `metric`, `normalize_embeddings`, timestamps, and record counts.
         * Atomically replaces destination files using `os.replace` with `manifest.json` replaced last as the commit sentinel, or atomically swaps the directory.
         * Documents limitations: On Windows, active open file handles lock files; if a crash occurs mid-write, previous committed index remains intact because staging files are isolated.
       - **Defensive index loading** in `load(directory, expected_model_name, expected_metric, expected_normalize)` (Safeguard 2, 9):
         * Validates existence of `manifest.json`, `index.faiss`, and `metadata.json`.
         * Reads `manifest.json` and asserts `status == "committed"`; raises `IndexCorruptionError("Uncommitted or partial index snapshot detected")` if missing or uncommitted.
         * Verifies checksums if present in manifest.
         * Verifies compatibility:
           - Asserts `manifest.dimension == self.dimension`, raising `IncompatibleIndexError(f"Dimension mismatch: expected {self.dimension}, found {manifest.dimension}")`.
           - If `expected_model_name`, asserts `manifest.model_name == expected_model_name`, raising `IncompatibleIndexError(f"Model mismatch: expected {expected_model_name}, found {manifest.model_name}")`.
           - Asserts `manifest.similarity_metric == self.metric` and `manifest.normalize_embeddings == self.normalize_embeddings`.
         * Reads `index.faiss` and `metadata.json`.
         * Verifies FAISS `index.ntotal == len(_records)`; raises `IndexCorruptionError("Vector count mismatch between FAISS and metadata sidecar")` if misaligned.
         * Rebuilds `_chunk_id_set` from loaded `_records`.
    4. Export in `src/documind/storage/__init__.py`.
  </action>
  <verify>
    `.venv\Scripts\python -c "from documind.storage.vector_store import FaissVectorStore, IncompatibleIndexError, IndexCorruptionError; vs = FaissVectorStore(dimension=384); assert vs.search(np.zeros(384, dtype=np.float32)) == []; print('FaissVectorStore verified')"` exits with code 0.
  </verify>
  <done>
    `FaissVectorStore` provides crash-consistent snapshots, defensive manifest validation, vector validation, and empty-index safety, satisfying Safeguards 1, 2, 5, 6, 9, and `EMBED-02`.
  </done>

<task type="auto">
  <name>Task 2: Implement High-Level DocumentIndex with Two-Level Deduplication and Telemetry</name>
  <files>src/documind/storage/index.py, src/documind/storage/__init__.py</files>
  <read_first>src/documind/storage/embedder.py, src/documind/storage/vector_store.py, src/documind/ingestion/schemas.py</read_first>
  <action>
    1. Create `src/documind/storage/index.py` with `DocumentIndex`:
       - Accepts optional `embedder: Optional[BaseEmbedder] = None` (defaults to `LocalEmbedder`).
       - Accepts optional `vector_store: Optional[BaseVectorStore] = None` (defaults to `FaissVectorStore(embedder.dimension)`).
       - Accepts optional `config: Optional[VectorStoreConfig] = None`.
       - Method `add_chunks(chunks: List[TextChunk]) -> IndexingResult` (Safeguards 4, 6):
         * Tracks `seen_in_batch: Set[str] = set()`.
         * Filters chunks sequentially:
           1. Discards empty or whitespace-only chunks (`not chunk.text or not chunk.text.strip()`), incrementing `empty_chunks_skipped`. Never embeds or indexes zero vectors.
           2. Discards intra-batch duplicates (`chunk.chunk_id in seen_in_batch`), incrementing `intra_batch_duplicates_skipped`.
           3. Discards existing index duplicates (`vector_store.contains_chunk(chunk.chunk_id)`), incrementing `existing_duplicates_skipped`.
           4. Valid unique chunks are added to `valid_chunks` list and `seen_in_batch`.
         * If `valid_chunks` is empty, returns `IndexingResult(len(chunks), 0, intra_dup, exist_dup, empty_dup)`.
         * Extracts text spans and embeds via `embedder.embed_texts([c.text for c in valid_chunks])`.
         * Converts `TextChunk` objects to `VectorRecord` objects with embeddings.
         * Adds vectors and records to `vector_store`.
         * Returns `IndexingResult(total_received=len(chunks), newly_indexed=len(valid_chunks), ...)`.
       - Method `add_documents(documents_chunks: Dict[str, List[TextChunk]]) -> Dict[str, IndexingResult]`:
         * Ingests multiple documents in sequence, tracking per-document `IndexingResult`.
       - Method `search(query: str, top_k: int = 5) -> List[SearchResult]` (Safeguard 6):
         * Rejects empty or whitespace-only queries with `ValueError("Search query cannot be empty or whitespace-only")`.
         * If `vector_store.total_vectors == 0`, returns `[]` immediately.
         * Embeds query string via `embedder.embed_text(query)`.
         * Queries `vector_store.search(query_vector, top_k)`.
         * Returns ranked results with scores and full chunk metadata.
       - Methods `save(path: Optional[Path] = None)` and `load(path: Path)`:
         * Manages persistent index storage on disk, passing active model parameters to validate compatibility.
    2. Export `DocumentIndex` in `src/documind/storage/__init__.py`.
  </action>

  </verify>
