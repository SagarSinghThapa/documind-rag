<objective>
Implement the core local embedding engine, offline configuration safeguards, explicit model provisioning, and storage schemas for DocuMind. Encapsulate model loading, CPU inference, batch vectorization, pre-insertion validation, and L2-normalization behind a clean `BaseEmbedder` abstraction, preserving all 12 document metadata attributes from Phase 1 and establishing strict offline runtime guarantees.

Purpose: Provide a fast, reliable, CPU-compatible dense embedding foundation (<15 ms latency per chunk) for vector indexing without paid APIs, cloud dependencies, or silent runtime network access.
Output: `src/documind/storage/schemas.py`, `src/documind/storage/embedder.py`, configuration additions in `src/documind/config.py`, provisioning script in `scripts/download_model.py`, and comprehensive test suite in `tests/test_embedder.py`.

  <files>src/documind/storage/embedder.py, src/documind/storage/__init__.py</files>
  <read_first>src/documind/config.py, src/documind/storage/schemas.py, .planning/phases/DOCU-02-wp-03-local-embeddings-and-persistent-vector-index/02-RESEARCH.md</read_first>
  <action>
    1. Create `src/documind/storage/embedder.py`:
       - Define custom exceptions:
         * `EmbedderError(Exception)`
         * `ModelNotFoundError(EmbedderError)`: Raised when local weights are missing and `local_files_only=True` or `allow_download=False`.
       - Define abstract `BaseEmbedder(ABC)` with:
         * `@property dimension -> int`
         * `@property model_name -> str`
         * `@property normalize_embeddings -> bool`
         * `embed_text(text: str) -> np.ndarray` (1D array of shape `(dimension,)`)
         * `embed_texts(texts: List[str], batch_size: Optional[int] = None) -> np.ndarray` (2D array of shape `(N, dimension)`)
       - Implement concrete `LocalEmbedder(BaseEmbedder)`:
         * **Offline runtime loading**: Checks model availability with `local_files_only=True`. If weights are missing and `allow_download=False`, raises `ModelNotFoundError` detailing the command `python scripts/download_model.py`.
         * **Empty input validation**:
           - `embed_text(text: str)`: Rejects empty or whitespace-only strings with `ValueError("Text to embed cannot be empty or whitespace-only")`.
           - `embed_texts(texts: List[str])`: If input list is empty, returns empty 2D array of shape `(0, dimension)`. If any string in batch is empty/whitespace, raises `ValueError` specifying the offending index (empty chunks must be filtered before batch embedding).
           - Never generates zero-vectors or NaN vectors.
         * **Vector validation helper** `validate_vectors(vectors: np.ndarray, expected_dim: int, must_be_normalized: bool = True) -> np.ndarray`:
           - Enforces `dtype=np.float32`.
           - Enforces memory contiguity: `np.ascontiguousarray(vectors, dtype=np.float32)`.
           - Validates shape: `(dimension,)` for 1D or `(N, dimension)` for 2D.
           - Asserts finiteness: `np.all(np.isfinite(vectors))` (raises `ValueError("Vectors contain NaN or Inf values")`).
           - If `must_be_normalized=True`, validates Euclidean norm $\approx 1.0 \pm 1e-3$.
         * Employs PyTorch CPU execution with `torch.inference_mode()` or `SentenceTransformer.encode(..., normalize_embeddings=True)`.
    2. Update `src/documind/storage/__init__.py` to export `BaseEmbedder`, `LocalEmbedder`, `EmbedderError`, and `ModelNotFoundError`.
  </action>
