         ```python
         class RetrievalQuery:

             document_id_filter: Optional[str] = None
         ```

       - `RetrievedChunk`:
         ```python
         @dataclass(frozen=True)
         class RetrievedChunk:
             chunk_id: str
             document_id: str
             document_name: str
             source_path: str
             chunk_index: int
             text: str
             page_numbers: List[int]
             start_page: int
             end_page: int
             char_start: int
             char_end: int
             score: float                                # Cosine similarity score [-1.0, 1.0]
             chunking_strategy: str = "recursive"
             chunk_size: int = 1000
             chunk_overlap: int = 150
             metadata: Dict[str, Any] = field(default_factory=dict)
             
             @classmethod
             def from_search_result(cls, result: SearchResult) -> "RetrievedChunk":
                 rec = result.record
                 return cls(
                     chunk_id=rec.chunk_id,
                     document_id=rec.document_id,
                     document_name=rec.document_name,
                     source_path=rec.source_path,
                     chunk_index=rec.chunk_index,
                     text=rec.text,
                     page_numbers=list(rec.page_numbers),
                     start_page=rec.start_page,
                     end_page=rec.end_page,
                     char_start=rec.char_start,
                     char_end=rec.char_end,
                     score=float(result.score),
                     chunking_strategy=rec.chunking_strategy,
                     chunk_size=rec.chunk_size,
                     chunk_overlap=rec.chunk_overlap,
                     metadata=dict(rec.metadata),
                 )
         ```
       - `RetrievalResult`:

         ```python
         @dataclass(frozen=True)
         class RetrievalResult:
             query: str
             chunks: List[RetrievedChunk]
             total_retrieved: int
             total_below_threshold: int
             embed_latency_ms: float                     # Pure query vectorization time
             search_latency_ms: float                    # Pure FAISS index lookup time
             total_latency_ms: float                     # Full retrieval pipeline latency
         ```

  <name>Task 2: Implement BaseRetriever and SemanticRetriever with Baseline & Filtering Support</name>
  <files>src/documind/retrieval/retriever.py, src/documind/retrieval/__init__.py</files>
  <read_first>src/documind/storage/index.py, src/documind/storage/vector_store.py, src/documind/retrieval/schemas.py</read_first>
  <action>
    1. Create `src/documind/retrieval/retriever.py` with:
       - `BaseRetriever(ABC)`:
         ```python
         class BaseRetriever(ABC):
             @abstractmethod
             def retrieve(self, query: Union[str, RetrievalQuery], top_k: Optional[int] = None) -> RetrievalResult:
                 pass
         ```
       - `SemanticRetriever(BaseRetriever)`:
         - Accepts `document_index: DocumentIndex`, `config: Optional[RetrievalConfig] = None`.
         - Validates input: rejects empty string, whitespace-only string, or non-string with `ValueError`.
         - Resolves parameters: `effective_top_k` and `effective_threshold` (checks query override, falls back to config).
         - Checks if index is empty (`document_index.total_vectors == 0`): returns empty `RetrievalResult(chunks=[], total_retrieved=0, total_below_threshold=0, embed_latency_ms=0.0, search_latency_ms=0.0, total_latency_ms=0.0)`.
         - Measures query embedding latency: `t0 = time.perf_counter()`, `query_vec = document_index.embedder.embed_text(query_str)`, `t_embed = (time.perf_counter() - t0) * 1000`.
         - Measures FAISS search latency: `t1 = time.perf_counter()`, `raw_results = vector_store.search(query_vec, top_k=effective_top_k)`, `t_search = (time.perf_counter() - t1) * 1000`.
         - If `document_id_filter` is specified, filters `raw_results` to matching `document_id`.
         - Applies threshold filtering if `effective_threshold is not None`:
           - Chunks with `score >= effective_threshold` are kept in descending score order.
           - Chunks with `score < effective_threshold` are omitted and counted in `total_below_threshold`.
         - If `effective_threshold is None`:
           - All retrieved chunks are retained (`total_below_threshold = 0`), preserving a no-threshold baseline.
         - Computes `total_latency_ms = (time.perf_counter() - t0) * 1000`.
         - Returns structured `RetrievalResult`.
    2. Update `src/documind/retrieval/__init__.py` to export `BaseRetriever` and `SemanticRetriever`.
  </action>
