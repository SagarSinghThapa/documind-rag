  <name>Task 1: Implement ContextBuilder with Dynamic Overlap Verification and Untrusted Text Encapsulation</name>
  <files>src/documind/retrieval/context_builder.py, src/documind/retrieval/__init__.py</files>
  <read_first>src/documind/retrieval/schemas.py, src/documind/config.py, .planning/phases/DOCU-03-wp-04-semantic-retrieval/03-RESEARCH.md</read_first>
  <action>
    1. In `src/documind/retrieval/context_builder.py`, implement:
       - `ContextReference`:
         ```python
         @dataclass(frozen=True)
         class ContextReference:
             document_name: str
             document_id: str
             source_path: str
             start_page: int
             end_page: int
             page_numbers: List[int]
             chunk_id: str
             chunk_index: int
             score: float
             char_start: int
             char_end: int
         ```
       - `FormattedContext`:
         ```python
         @dataclass(frozen=True)
         class FormattedContext:
             text: str
             references: List[ContextReference]
             total_chars: int
             estimated_tokens: int
             chunks_included: int
             chunks_discarded_budget: int
             context_build_latency_ms: float
         ```
       - `ContextBuilder`:
         - Initialized with `max_chars: int = 4000`, `deduplicate_overlap: bool = True`, `min_overlap_chars: int = 20`.
         - Method `build(chunks: List[RetrievedChunk]) -> FormattedContext`:
           - If `chunks` is empty, returns empty `FormattedContext` with 0 counts.
           - Measures formatting latency: `t0 = time.perf_counter()`.
           - Groups and sorts chunks: preserves similarity rank order for chunk selection.
           - Dynamic Overlap Deduplication:
             For consecutive chunks from the same document (`curr.document_id == prev.document_id` and `curr.chunk_index == prev.chunk_index + 1`):
               Scans suffixes of `prev.text` and prefixes of `curr.text` to find the exact maximal matching string.
               Only strips duplicate text if the verified match length is `>= min_overlap_chars`.
               If no verified match is found (e.g. non-overlapping split), leaves chunk text completely intact.
           - Encapsulation of Untrusted Document Content:
             Formats each included chunk with distinct structural markers:
             ```markdown
             ### Source: {document_name} | Physical Page(s): {page_span} | Ref ID: {chunk_id}
             > [Document Content - Untrusted Context]
             > {escaped_chunk_text}
             ```
           - Budget Packing: Appends chunks in priority order. If adding the next chunk exceeds `max_chars`, omits subsequent chunks and increments `chunks_discarded_budget`. Does not truncate mid-word.
           - Populates `ContextReference` records for every included chunk preserving all original character offsets and page numbers.
           - Records `context_build_latency_ms = (time.perf_counter() - t0) * 1000`.
    2. Export `ContextBuilder`, `ContextReference`, and `FormattedContext` in `src/documind/retrieval/__init__.py`.
  </action>

       - Ground-truth relevance is verified against actual physical page numbers and exact verbatim excerpts from the PDF text (no assumed or fabricated labels).
       - Schema per item:
         ```json
         {
           "query_id": "CALIB-01",
           "split": "calibration",
           "query": "What are the core components of a retrieval-augmented generation system?",
           "is_negative": false,
           "expected_document": "BASWE-15-RAG-Concepts-Guide.pdf",
           "expected_pages": [2, 3],
           "verified_excerpt": "combines an information retrieval system with a generative language model",
           "notes": "Verified on page 2-3 of BASWE guide"
         }
         ```
       - Negative distractors (e.g., sourdough baking, car maintenance, tax filing) have `is_negative: true`, `expected_document: null`, `expected_pages: []`.
    2. Create `src/documind/retrieval/evaluator.py`:
       - `RetrievalMetrics`:
         ```python
         @dataclass(frozen=True)
         class RetrievalMetrics:
             total_queries: int
             positive_queries: int
             negative_queries: int
             recall_at_k: float                      # Computed solely on positive queries with |Relevant| > 0
             precision_at_k: float                   # Computed on positive queries
             mrr: float                              # Computed on positive queries (0.0 if not found in top K)
             negative_rejection_rate: float          # Fraction of negative queries returning 0 chunks above threshold
             false_positive_rate: float              # 1.0 - negative_rejection_rate
             attribution_accuracy: float             # Fraction of retrieved chunks matching verified document/page
             # Disaggregated Latency Profiles (ms)
             embed_latency_mean: float
             embed_latency_median: float
             embed_latency_p95: float
             search_latency_mean: float
             search_latency_median: float
             search_latency_p95: float
             context_latency_mean: float
             context_latency_median: float
             context_latency_p95: float
             total_latency_mean: float
             total_latency_median: float
             total_latency_p95: float
         ```
       - `RetrievalEvaluator`:
         - Evaluates a `BaseRetriever` and optional `ContextBuilder` against a dataset split.
         - Computes exact formulas for Recall@K, Precision@K, MRR, NRR, and stage-by-stage latencies.
    3. Create standalone CLI `scripts/evaluate_retrieval.py`:
       - Flags: `--ground-truth`, `--top-k`, `--sweep-thresholds`, `--split`.
       - Workflow:
         - Sweeps $\tau \in [0.10, 0.60]$ (step 0.05) on the **calibration split (Split A)** to identify optimal $F_1$ and NRR.
         - Evaluates the chosen threshold on the **holdout evaluation split (Split B)** to report unbiased generalization.
         - Displays stage-by-stage latency percentiles (mean, median, P95).
