         - If matched: creates verified `Citation(..., is_metadata_valid=True, matched_chunk_id=ref.chunk_id)`.
         - If unmatched: flags citation with `is_metadata_valid=False` and appends to `hallucinated_citations`.
         - Evaluates evidence support heuristic: checks if key factual terms from the sentence appear in the referenced chunk text.

<task type="auto">
  <name>Task 2: Implement GroundedGenerator with Conservative Fallbacks and Dual-Tier Abstention</name>
  <files>src/documind/generation/generator.py, src/documind/generation/__init__.py</files>
  <read_first>src/documind/generation/llm.py, src/documind/generation/prompts.py, src/documind/generation/citation.py, src/documind/retrieval/retriever.py</read_first>
  <action>
    1. In `src/documind/generation/generator.py`, implement `GroundedGenerator`:
       - Accepts `retriever: BaseRetriever`, `llm: BaseLLM`, `context_builder: Optional[ContextBuilder] = None`, `config: Optional[GenerationConfig] = None`.
       - Method `generate_answer(query: str, top_k: Optional[int] = None, similarity_threshold: Optional[float] = None) -> GroundedAnswer`:
         - Measures pipeline latency.
         - Retrieves chunks: `res = self._retriever.retrieve(query, top_k=top_k, similarity_threshold=similarity_threshold)`.
         - **Fast-Path Abstention:** If `len(res.chunks) == 0`:
           Returns `GroundedAnswer(query=query, answer=self._config.abstention_phrase, is_abstained=True, abstention_type="fast_path_empty_context", grounding_status="abstained", citations=[], hallucinated_citations=[], context=empty_context, telemetry={...})`.
         - Builds context: `ctx = self._context_builder.build(res.chunks)`.
         - If `ctx.chunks_included == 0`:
           Returns fast-path abstention (`abstention_type="fast_path_empty_context"`).
         - Builds prompt: `messages = build_grounded_prompt(query, ctx)`.
         - Calls `self._llm.generate(messages, max_new_tokens=self._config.max_new_tokens, temperature=self._config.temperature)`.
         - **Model-Level Abstention Check:**
           Checks if output matches `self._config.abstention_phrase` or contains clear abstention phrases ("cannot answer", "does not contain", "no information"):
           If so, sets `is_abstained=True`, `abstention_type="model_explicit"`, `grounding_status="abstained"`.
         - **Citation & Evidence Verification:**
           Extracts citations using `CitationParser.extract_citations()`.
           Verifies against `ctx.references` via `CitationParser.verify_citations()`.
         - **Conservative Fallback:**
           If the answer makes factual claims but has 0 valid citations or only hallucinated citations, flags `grounding_status="unsupported"`.
           If citations are partially verified, flags `grounding_status="partially_supported"`.
           If all citations valid and verified, flags `grounding_status="verified"`.
         - Assembles and returns structured `GroundedAnswer`.
    2. Export `GroundedGenerator` in `src/documind/generation/__init__.py`.
  </action>
  <verify>
    <command>python -c "from documind.generation import GroundedGenerator; print('GroundedGenerator imported successfully')"</command>
  </verify>
</task>
