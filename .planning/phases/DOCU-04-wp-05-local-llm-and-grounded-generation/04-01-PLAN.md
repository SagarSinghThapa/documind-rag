  <action>
    1. In `src/documind/config.py`, add `GenerationConfig`:
       ```python
       @dataclass(frozen=True)
       class GenerationConfig:
           model_name: str = "Qwen/Qwen2.5-0.5B-Instruct"  # Initial lightweight CPU baseline
           max_new_tokens: int = 512
           temperature: float = 0.0                        # Deterministic generation
           top_p: float = 1.0
           device: str = "cpu"
           local_files_only: bool = True                   # Strict offline runtime default
           allow_download: bool = False
           cache_folder: Optional[str] = None
           abstention_phrase: str = "I cannot answer this question based on the provided document context."
       ```
    2. Create `src/documind/generation/schemas.py`:
       - `GenerationRequest`: Encapsulates prompt/messages, max_tokens, temperature.
       - `GenerationResult`: Raw text, tokens generated, prompt tokens, generation_latency_ms, tokens_per_sec.
       - `Citation`:
         ```python
         @dataclass(frozen=True)
         class Citation:
             raw_text: str                       # e.g. "[Source: BASWE-15-RAG-Concepts-Guide.pdf, p. 3]"
             document_name: str                  # e.g. "BASWE-15-RAG-Concepts-Guide.pdf"
             start_page: int                     # e.g. 3
             end_page: int                       # e.g. 3
             matched_chunk_id: Optional[str]     # Linked chunk ID from ContextReference
             is_syntax_valid: bool               # Layer 1: Regex syntax check
             is_metadata_valid: bool             # Layer 2: Mapped to actual ContextReference
             is_evidence_supported: bool = False # Layer 3: Factual proposition check
         ```
       - `GroundedAnswer`:
         ```python
         @dataclass(frozen=True)
         class GroundedAnswer:
             query: str
             answer: str
             cited_source_ids: List[str]         # Unique chunk IDs cited
             citations: List[Citation]
             is_abstained: bool
             abstention_type: Optional[str]      # "fast_path_empty_context", "model_explicit", "fallback_unsupported", None
             grounding_status: str               # "verified", "partially_supported", "unsupported", "abstained"
             context: FormattedContext
             telemetry: Dict[str, Any]           # prompt_tokens, completion_tokens, cold_load_ms, ttft_ms, tokens_per_sec, total_latency_ms
         ```
    3. Initialize `src/documind/generation/__init__.py`.
  </action>
